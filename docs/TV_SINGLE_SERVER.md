## Global Route Map

目标：182 承载站点、播放代理、APK、更新清单；新客户端不依赖 106。
范围：Android 默认更新源、代理媒体类型识别和请求路径、182-only APK 发布。
不改网站业务、片源配置、生产其他服务；不删除 106 历史兼容文件。

## 目标拓扑

```text
电视 APK ── HTTPS ── 182 / kvideo.djjk.cc
                       ├─ 站点 / API / 播放代理
                       ├─ /api/tv-update
                       └─ /ziqidonglai/ziqidonglai-tv-v<code>.apk
```

代理目标只用于判断媒体类型，不应替换实际请求 URL。
PlayerActivity 必须根据同一解析器识别 HLS，否则 /api/proxy 没有 .m3u8 后缀会误用渐进式源。

## 兼容与回滚边界

- 旧 APK 的双源检查仍会访问 182，新版本码必须高于当前线上版本，不能复用 41003。
- 106 只保留现有文件，不再作为新版发布目标。这里的“单服务器”指新版运行和更新依赖，并非删除另一台服务器。
- 清单使用版本化 APK URL，避免旧清单下载到被覆盖的 latest.apk。
- 服务端恢复备份只影响后续下载，不能让已安装高版本的 Android 自动降级。
- 已升级客户端需要修复版时，使用更高 versionCode、同生产签名重新发布。
- 单测和浏览器假桥不等于电视解码、遥控或长播通过。
